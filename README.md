# Спортивная драма

Для работы серверу нужны переменные окружения Render:

- `DATABASE_URL` — строка подключения к Neon.
- `ADMIN_PASSWORD` — пароль руководителя для раздела «Настройки». Задайте его в **Render → Web Service → Environment**; не добавляйте пароль в репозиторий.

После добавления `ADMIN_PASSWORD` Render перезапустит сервис. Руководитель открывает «Настройки», вводит пароль и получает доступ к параметрам игры, челленджам и истории с откатом. Сессия действует 8 часов; кнопка «Выйти» завершает её раньше. Если пароль заменить в Render, старые сессии перестанут работать.

Запись состояния новой команды впервые выполняет руководитель после входа. Последующие обычные игровые действия доступны без пароля; сервер отклоняет попытки изменить настройки, зачёты челленджей или прошлую историю без авторизации.

В настройках руководитель может менять цены и названия наград, отмечать их как супер-призы, задавать общий лимит на отдел и добавлять новые позиции. Каталог магазина общий для четырёх команд и хранится в `department_shop`. По умолчанию сертификат 1 000 ₽, кино от босса, Day off и оплата у робота Алёши — супер-призы с лимитом 5 покупок каждого на весь отдел. Один менеджер может покупать их повторно, пока есть общий остаток. Счётчики покупок хранятся в `super_prize_inventory` и не обнуляются при начале нового периода. При первом включении общего лимита для ранее ограниченных наград текущие неотменённые покупки учитываются в остатке; при превращении обычной награды в супер-приз её прежние обычные покупки не считаются. Снижение лимита ниже уже купленного показывает нулевой остаток. Отмена невыданной покупки возвращает единицу в остаток. Индивидуальная гифка — обычная награда без ограничения по количеству.
